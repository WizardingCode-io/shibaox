Starting Shibaox

Reaching the shibaox daemon, starting it when it is not running. A few seconds.

Shibaox cannot reach a daemon

The shibaox daemon is not running.

Start it in a terminal with shibaox daemon start --detach (install it first with npm i -g shibaox), or point this app at a remote daemon with shibaox remote set <url> <token>. The daemon's log is ~/.shibaox/daemon.log.

Try again
